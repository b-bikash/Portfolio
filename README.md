## 📖 Overview

This repository contains the source code for my personal portfolio website. It serves as a central place where recruiters, developers, and visitors can learn more about me, explore my projects, and get in touch.

The website includes:

- 👨‍💻 About Me
- 🛠 Technical Skills
- 📂 Featured Projects
- 💼 Professional Experience
- 🎓 Education
- 📬 Contact Form
- 📄 Resume Download

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/b-bikash/Portfolio.git
```

### Navigate to the project

```bash
cd Portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```
